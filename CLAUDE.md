# OpenPulse — notes for Claude

WHOOP-style iOS app (SwiftUI, iOS 17+, Swift 5 language mode, **no third-party dependencies**) that talks directly over
Bluetooth to a CMF Watch 3 Pro (proprietary CMF protocol) and to any standard BLE heart-rate sensor, stores data in
SwiftData on the phone, and computes Recovery / Strain / Sleep scores plus coaching feedback. See README.md.

## The owner has no Mac
All compiling and testing happens on GitHub Actions (`.github/workflows/ios.yml`, runner `macos-15`):
1. Device build with signing disabled → artifact **OpenPulse-unsigned-ipa** (installed on the iPhone with Sideloadly).
2. Unit tests on the newest iPhone simulator.

After every push, check the workflow run and read the errors. Use whatever is available, in this order: `gh run list` /
`gh run view <id> --log-failed`, GitHub MCP tools, the REST API with `$GITHUB_TOKEN`, or the `build-logs` artifact.
If none of these can reach CI, ask the owner to open the Actions tab and paste the red step's log. Iterate until the
run is green. Each macOS run costs CI minutes, so batch all fixes you can see into one push.

## Rules
- Keep fixes minimal and targeted. Don't restructure or "modernise" working code while chasing compiler errors.
- Keep `SWIFT_VERSION = 5.0`; don't enable strict concurrency. `HealthStore` is `@MainActor`; Bluetooth classes are
  not, and hand data to the store via `Task { @MainActor in … }`.
- **Never edit the expected hex values in `OpenPulseTests`.** They were generated by an independent Python
  implementation of the CMF protocol. If a protocol test fails, the Swift code is wrong.
- Score calibration (HRR threshold 0.25, TRIMP/150, sleep-z centred at 80, non-compounding sleep debt) was tuned by
  simulation — change it only on purpose, and update README + `MethodologyView` text together.
- Bluetooth can't be tested in CI or the simulator. Real-device problems are diagnosed from the in-app
  *Devices › Bluetooth log*, which the owner can share.
- New wearable brands: subclass `WearableDriver`, conform to `CBPeripheralDelegate`, emit `HealthBatch`es, add a
  `DeviceKind` case and wire it in `BluetoothManager`.

## Layout
`OpenPulse/` app sources (Xcode 16 synchronized folder — new files are picked up automatically, no pbxproj edits
needed) · `OpenPulseTests/` unit tests · `Config/Info.plist` (Bluetooth background mode) · `tools/make_icon.py`
regenerates the app icon.
